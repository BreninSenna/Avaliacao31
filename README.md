## Codigo em linha e blocos de código

Use uma crase `git status` mostra o estado atual do repositório.

O comando `git add .` adiciona os arquivos á *stagingarea*

O comando `git commit -m "Comentario da descrição sobre a alteração"` regitras as alterações com uma mensagem. 

O comando `git push` sobe as alterações para a nuvem.

```

git status
git add .
git commit -m "Texto com a descrição do que foi implementado"
git push

```
